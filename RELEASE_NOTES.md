# v0.1.0-alpha local release candidate

First community alpha of Portable Work / Execution Receipt. This is not an official FLOP Labs product.

It records cross-system evidence with explicit verification and coverage states. It does not prove execution correctness by itself, implement settlement, replace native FLOP receipts, or turn signed/venue data into truth.

The release artifact is `flop-tools-work-execution-receipt-0.1.0.tgz`; its SHA-256 is generated after the final committed tree is packed.
